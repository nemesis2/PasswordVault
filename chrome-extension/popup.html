      🔒︎ Vault Autofill Companion

      ℹ︎ Description

      A companion for your self-hosted, client-side-encrypted vault. It reads the same ciphertext the vault already serves and decrypts it locally in the browser, then autofills logins on matching sites. Read-only — use the vault web app (Edit) to add or change entries. Passwords are never stored — only the vault URL is saved. Decrypted secrets live only in memory and are wiped on lock / 5-min idle. The only network request is fetching your vault; nothing is sent elsewhere.

      ⏲︎ Auto-Lock

      When enabled, the vault locks after 5 minutes of true system inactivity (or when the screen locks). Disabling keeps decrypted secrets in memory until you lock manually or close the browser.
